# Markdown to ADF Conversion Enhancement

## Overview

This enhancement converts all agent output comments from plain Markdown wrapped in code blocks to properly formatted **Atlassian Document Format (ADF)** for significantly improved rendering in Jira and Confluence.

## Problem Statement

### Before
Agent outputs were posted to Jira comments wrapped in a markdown code block:

```typescript
{
  type: 'codeBlock',
  attrs: { language: 'markdown' },
  content: [{ type: 'text', text: comment }],
}
```

**Result:** Markdown syntax was visible but not rendered (showed as raw text):
```
# SENTRY Review
**Status:** APPROVED
- Item 1
- Item 2
```

### After
Agent outputs are now converted to native ADF format:

```typescript
{
  type: 'doc',
  version: 1,
  content: [
    { type: 'heading', attrs: { level: 1 }, content: [{ type: 'text', text: 'SENTRY Review' }] },
    { type: 'paragraph', content: [{ type: 'text', text: 'Status:', marks: [{ type: 'strong' }] }, ...] },
    { type: 'bulletList', content: [...] },
  ]
}
```

**Result:** Proper rich text formatting with headings, bold, lists, tables, etc.

## Implementation

### 1. Library Selection
We use **`marklassian`** - a lightweight Node.js library specifically designed for Markdown → ADF conversion.

#### Installation
```bash
npm install marklassian
```

#### Why marklassian?
- ✅ Purpose-built for Atlassian platforms
- ✅ Supports most common Markdown features (headings, lists, tables, code blocks, links, bold/italic)
- ✅ Lightweight with minimal dependencies
- ✅ Actively maintained
- ✅ TypeScript compatible

### 2. Utility Module

Created `/src/utils/markdown-to-adf.ts` with the following functions:

#### `convertMarkdownToAdf(markdown: string): AdfDocument`
Main conversion function that transforms Markdown to ADF.

```typescript
import { convertMarkdownToAdf } from '../utils/markdown-to-adf.js';

const markdown = `
# SENTRY Review
**Status:** APPROVED
- Check 1: PASS
- Check 2: PASS
`;

const adf = convertMarkdownToAdf(markdown);
// Returns ADF document ready for Jira API
```

#### `convertMarkdownToAdfWithHeading(markdown: string, heading?: string): AdfDocument`
Adds a custom heading before the converted content.

```typescript
const adf = convertMarkdownToAdfWithHeading(markdown, 'Agent Analysis Result');
```

#### `addAdfFooter(adf: AdfDocument, agentName?: string): AdfDocument`
Appends a timestamp footer to the ADF document.

```typescript
const adfWithFooter = addAdfFooter(adf, 'SENTRY Agent');
// Adds: "Generated by SENTRY Agent at 2024-02-08T10:30:00.000Z"
```

#### `validateAdf(adf: any): adf is AdfDocument`
Type guard to validate ADF structure.

```typescript
if (validateAdf(adf)) {
  // Safe to use as AdfDocument
}
```

## Supported Markdown Features

marklassian supports the following Markdown elements:

### Text Formatting
- **Bold** (`**text**` or `__text__`)
- *Italic* (`*text*` or `_text_`)
- `Inline code` (`` `code` ``)
- ~~Strikethrough~~ (`~~text~~`)

### Headings
```markdown
# H1
## H2
### H3
#### H4
##### H5
###### H6
```

### Lists
```markdown
- Unordered list item 1
- Unordered list item 2
  - Nested item

1. Ordered list item 1
2. Ordered list item 2
   1. Nested ordered item
```

### Code Blocks
````markdown
```python
def hello():
    print("Hello, World!")
```
````

### Links
```markdown
[Link text](https://example.com)
```

### Tables
```markdown
| Header 1 | Header 2 |
|----------|----------|
| Cell 1   | Cell 2   |
| Cell 3   | Cell 4   |
```

### Blockquotes
```markdown
> This is a blockquote
> Multiple lines supported
```

### Horizontal Rules
```markdown
---
```

### Task Lists
```markdown
- [x] Completed task
- [ ] Incomplete task
```

## Error Handling

The converter includes comprehensive error handling:

```typescript
try {
    const adf = markdownToAdf(markdown);
    return adf;
} catch (error) {
    logger.error('Failed to convert markdown to ADF', { error });

    // Fallback: wrap in code block (old behavior)
    return {
        version: 1,
        type: 'doc',
        content: [{
            type: 'codeBlock',
            attrs: { language: 'markdown' },
            content: [{ type: 'text', text: markdown }],
        }],
    };
}
```

**Fallback behavior:** If conversion fails, the system reverts to the original code block format to ensure comments are still posted.

## Alternatives Considered

### 1. @hesto2/md-to-adf
- Less popular
- Limited documentation
- Similar functionality to marklassian

### 2. Atlaskit Transformers (Official)
- More accurate conversion
- Much heavier (~50MB+ dependencies)
- Overkill for our use case
- Requires `@atlaskit/adf-schema`, `@atlaskit/editor-json-transformer`, `@atlaskit/editor-markdown-transformer`

### 3. Custom Implementation
- More control
- High maintenance burden
- Would take weeks to implement properly
- Not worth the effort

**Decision:** marklassian offers the best balance of simplicity, features, and reliability.
