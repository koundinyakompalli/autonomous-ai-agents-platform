Specter

Specter is an asynchronous AI-agent platform with three runtime surfaces: the JIRA orchestrator, specialized workers, and Harvey for Microsoft Teams intake.

The active runtime is based on the shared Claude Agent SDK wrapper, shared S3 task and result buckets, and shared EFS repositories. Older Phoenix and MCP references are preserved only where a filename remains for continuity.

Claude Agent SDK JIRA Orchestrator Harvey Teams Bot Shared EFS Shared S3 Buckets

Runtime Surfaces

Orchestrator

Polls JIRA, enriches issues, writes task records, and posts completed JIRA results back.

Workers

Claim tasks, prepare EFS workspaces, run agent logic, and upload markdown results to S3.

Harvey

Accepts Teams requests, routes them into the same task pipeline, and proactively delivers results.
