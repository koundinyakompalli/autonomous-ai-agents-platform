Specter Platform

Asynchronous AI Agents for Engineering Work

Specter routes work from JIRA and Microsoft Teams into specialized workers that analyze code, validate SQL, plan changes, and return structured markdown results. It is designed around durable handoff rather than synchronous request/response execution.

Current result storage model: one shared results bucket, partitioned by key prefix.

Runtime Surfaces

Orchestrator

Polls JIRA, enriches issues, stages task markdown, and posts completed JIRA results back.

Workers

Claim durable tasks, prepare workspaces on EFS, run agent logic, and upload result markdown.

Harvey

Converts Teams conversations into task assignments and proactively delivers results back to chat.

Operational Notes

  • The active runtime is Claude SDK-based, not the older Phoenix execution model.
  • Harvey uses the same durable task pipeline as JIRA work instead of a custom side path.
  • Workers started through worker-main expose REST, SSE, and WebSocket status endpoints.
  • The repository also contains a separate Next.js marketing app under marketing/.
